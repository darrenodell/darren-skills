# Methodology v1
Python 3.10+ and zoneinfo; standard library only. Default benchmarks SPY, QQQ, IWM, RSP, XLK, SMH; configurable max10. Core rubric requires these six; a custom universe is supported for collection but reports INSUFFICIENT EVIDENCE if required defaults are missing.

Historical-only official Alpaca GETs: /v2/calendar on official paper/live host and /v2/stocks/{symbol}/bars on data.alpaca.markets. Runtime ALPACA_KEY/ALPACA_SECRET or APCA_API_KEY_ID/APCA_API_SECRET_KEY. Optional ALPACA_BASE_URL selects only official paper/live calendar hosts. Redirects rejected, secrets never output, bounded retries. Calendar includes early-close metadata; daily aggregation is provider-supplied. 250 prior exchange sessions before current NY date, even after close. Freshness for a new assessment: final session no older than five calendar days. Previous dated reports remain dated evidence.

SIP default, explicit --allow-iex-fallback retries whole benchmark set. Failed attempts are retained in manifest/snapshot. IEX is single venue. adjustment=all; percent changes of adjusted closes are not a guaranteed investable total-return series. SMA20/50/200, returns1/5/20/63/126, 20 log-return sample volatility times sqrt(252), worst peak-to-trough drawdown within included window. Return252 is null at250 closes. Relative change is (numerator terminal/initial)/(denominator terminal/initial)-1 on identical sessions.

FRED CSVs from fred.stlouisfed.org/graph/fredgraph.csv require no API key. Required DGS10, CPIAUCSL, UNRATE, FEDFUNDS; optional PAYEMS, GDPC1, VIXCLS, BAMLH0A0HYM2, NFCI. Daily series allow7 calendar days, monthly75, quarterly150, weekly18. Age is measured from the observation date for daily/weekly series and calendar period end for monthly/quarterly series, never from an assumed publication date. These are explicit lags/tolerances, not assurances of up-to-the-minute data. Monthly/quarterly date labels are periods, publication dates unknown in CSV, latest downloaded vintage can contain revisions. Re-check source terms before reuse, especially ICE/Cboe series. No licensed data in Git. A current FOMC target range is primary policy evidence; monthly FEDFUNDS is realized effective rate, not that target.

Rubric v1 is an unvalidated heuristic. Broad component averages SPY/QQQ trend: +1 for close>SMA50>SMA200, -1 for reverse, else0. Tech uses mean63-session XLK/SPY and SMH/SPY relative changes. Participation uses mean63-session RSP/SPY and IWM/SPY. SUPPORTIVE: broad>0, tech>0, participation>=0, no observed stress flags. ADVERSE: broad<0 and (tech<=0 or stress present). Else MIXED. Stress thresholds VIX>=30, HY OAS>=5 percentage points, NFCI>=0.5. Missing required data forces INSUFFICIENT EVIDENCE; optional stress missing is disclosed. Confidence moderate when required inputs pass, low otherwise; never a win probability. Correlated ratios are grouped, not independent votes. Macro values are contextual and a coverage gate, not causal forecasts.

## Authored primary context
Write JSON with an items array. Each item has strings title, source_url (HTTPS), publication_date (YYYY-MM-DD, or null when unknown), event_date (YYYY-MM-DD), retrieved_utc (timezone-aware ISO8601), summary and equity_implication. Example subject: a verified inflation release and its effect on financing/discount rates. Preserve planned versus completed events in text; retrieval is not publication. Verify reported facts, use primary citations and label inference. No context file means a disclosed quantitative baseline, not complete qualitative market/sector diligence.

Core does not supply consensus, actual constituent breadth, flows, earnings revisions, ownership or live borrow. No buy/sell execution calls, allocations, account reads or schedule.

Primary references: [Alpaca bars](https://docs.alpaca.markets/us/reference/stockbars), [FRED](https://fred.stlouisfed.org/), [Fed calendar](https://www.federalreserve.gov/monetarypolicy/fomccalendars.htm), [BLS releases](https://www.bls.gov/bls/newsrels.htm), [BEA](https://www.bea.gov/news).
